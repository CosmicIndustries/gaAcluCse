Glynn County Georgia Court Directory

The Georgia trial court system consists of Superior Courts, State Courts, Juvenile Courts, Probate Courts, Magistrate Courts, Civil Courts, Municipal Courts, and Recorder's Courts. For more information on which types of cases each court oversees, compare Georgia courts.

Below is a directory of court locations in Glynn County. Links for online court records and other free court resources are provided for each court, where available. If you’re not sure which court you’re looking for, learn more about the Georgia court system.
